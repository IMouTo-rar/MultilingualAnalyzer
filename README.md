# MultilingualAnalyzer

基于 IK Analyzer 修改而来的多语言分词器，兼容 `Java 17`、`Lucene 9.10`。

## License

本项目基于 [IK Analyzer](https://code.google.com/archive/p/ik-analyzer/) 修改而来，原作者：林良益（linliangyi2005@gmail.com）。

主要修改内容：

- 迁移至 Java 17
- 适配 Apache Lucene 9.10
- 重构包结构
- 加入多语言分词支持
